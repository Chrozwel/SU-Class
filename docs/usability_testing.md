# Usability Testing

We defined two primary tasks for testing: (1) identify at what time CO₂ levels
peak and (2) compare air temperature with relative humidity over several hours.
Ten classmates were asked to load the page and perform these tasks while
providing feedback.

Most participants easily located the dropdown menu and switched between
variables. Several noted that the time labels on the horizontal axis could be
more readable, so we increased the chart width and added clearer tick marks.
When searching for peak values, three users wanted a tooltip with exact numbers
on hover. This was added using built-in Chart.js options.

Overall the simplified interface allowed users to focus on exploring data rather
than deciphering the controls. We also clarified instructions in the short text
at the top of the page to guide first-time visitors.
