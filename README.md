# SU-Class IEQ Demo

This repository contains a simple demonstration of an Indoor Environment Quality
monitor as a static web page. Open `web/index.html` in a modern browser to load
the interactive chart. Data is provided in `data/sample_ieq.csv`.
Libraries for Chart.js and D3 are bundled in `web/lib` so the page can be opened offline.

Documentation describing the visualisation narrative, usability testing and
references is located in the `docs` folder.
